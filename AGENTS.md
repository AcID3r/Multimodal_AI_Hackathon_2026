# Project collaboration conventions

Follow the requirements in docs/PRD.md and the extracted problem statement.
Keep docs/task.md accurate: distinguish code written, verification passed, and external deliverables still pending.
After implementation changes, update docs/CODE_REVIEW_GUIDE.md and docs/everythingyoushouldknow.md.
At the end of every work session, tell the user what changed, what was tested, what remains, and the ordered files and commands to revise the code.
Never present synthetic tones as real speeches, approximate word timings as forced alignment, or fixture metrics as real speech accuracy.
Do not overwrite imported reviewed recordings. Preserve attribution and label provenance.
