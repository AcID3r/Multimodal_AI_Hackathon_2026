# 3-10 minute demo video plan

This is a recording script; no video has been recorded or uploaded.

| Time | Show | Say / demonstrate |
|---|---|---|
| 0:00-0:45 | Problem statement and dashboard | Same words can be delivered very differently; feedback should identify where and explain measured differences. |
| 0:45-2:00 | Dataset folders, attribution, reviewed real transcript and labels | Explain ideal baseline sourcing and how three controlled severities preserve text. Until real speeches are imported, identify fixtures as synthetic tones and do not claim the real-data requirement is met. |
| 2:00-3:00 | Reference analysis then severity gradient | Identical audio gives no flaws. Compare scores and feature overlays across levels. Explain unexpected false detections honestly. |
| 3:00-4:30 | A real participant upload with reviewed timing JSON or verified WhisperX | Show same-text validation, waveform, corresponding-word feature mapping, timestamped explanation and its formula. |
| 4:30-5:30 | Playback, highlighted words, practice card, JSON export | Seek a detected section, listen to the baseline, inspect mathematical evidence and export the report. |
| 5:30-6:15 | Test run and evaluation report | Show three-run repeatability. Distinguish fixture tests from real-speech precision and boundary validation. |
| 6:15-7:00 | README, technical PDF and limitations | Show reproducible setup, attribution link, rubric methodology and honest remaining limitations. |

Before recording: import >=5 reviewed real speeches, review variant timings/labels, run submission validation, validate on held-out speeches, test browser interactions, replace pending dataset/repository links, and remove any claim unsupported by the evaluation report.

Record with OBS or a screen recorder, keep the final video between 3 and 10 minutes, upload it to YouTube, and add the actual URL to README and the DevPost form. Publication remains a separate external deliverable.
